**Описание**
Курсовая работа "Проект 2. "Поиск вакансий" в парадигме "Объектно-ориентированное программирование(ООП)"  
по специальности "Разработчик Python" университета Skypro.  

Задачи выполняемые программой: получение информации о вакансиях с платформы hh.ru в России, сохраннение ее в файл,  
добавление, фильтрация и удаление вакансий.  

**Для пользователей:**  

Установка: `poetry install --no-dev`  

Запуск: `python main.py`  

Пример запроса:  
> python main.py  
> Введите запрос: "Python"  
> Введите диапазон зарплат: "100000-150000"  


**Для разработчиков:**  

Установка; `poetry install`  

**Требуемые версии:**  
- Python 3.13.1
- poetry-core>=2.0.0,<3.0.0

**Зависимости:**  
	"pytest (>=8.3.4,<9.0.0)",  
    "requests>=2.31.0",  
    "pandas>=2.0.0",  
    "python-dotenv>=1.0.0",  
 
**Точка входа**: `main.py`  

**Структура:**  
	Модуль api_client.py содержит класс `HHAPIClient`: получает данные с HH.ru (3 страницы по 100 вакансий).  
	**Особенности работы с API HH.ru:**  
		- Задержка между запросами**: 0.1 сек (для 1-19 страниц) или 0.5 сек (20+ страниц).  
		- Пауза ставится после каждого запроса**, кроме последнего, во избежание лишнего ожидания.  
	Модуль analyzer.py содержит классы:  
		- 'Vacancy': хранит данные вакансии и методы сравнения.  
		- 'VacancyAnalyzer': фильтрует и сортирует вакансии.  
	Модуль storage.py содержит класс 'JSONSaver': чтение, сохранение отфильтрованных вакансий в файлы форматов  
		JSON и XLSX, добавление  и удаление вакансий.  
	Модуль utils.py содержит функцию 'check_exist_data': выполняет проверку существования файла данных  
		соответствующего запросу, если время существования файла превышает 1 час производится обращение к  
		`HHAPIClient` для запроса и получения свежих данных.  
	Модуль config.py содержит константы и настройку логирования для всего проекта.  
		
**Схема потока данных:**  
[Пользователь] → [main.py] → ['check_exist_data'] → [HHAPIClient] → [Vacancy] → ['VacancyAnalyzer'] → ['JSONSaver']
